# Política de segurança — CCA Central de Carregamentos

Vale para todos os repositórios da organização que não tragam um `SECURITY.md` próprio.

## Como relatar uma vulnerabilidade

**Não abra issue nem discussão pública.** Escreva para **contato@ccacarregamentos.com.br** com o assunto `[SEGURANÇA] <resumo>`. Inclua:

1. O sistema ou endereço afetado.
2. Como reproduzir, passo a passo.
3. O impacto que você observou.
4. Se for o caso, o seu contato para retorno.

Assuntos de dados pessoais (LGPD) vão para **privacidade@ccacarregamentos.com.br**.

## O que fazemos com o relato

- Confirmamos o recebimento em até **2 dias úteis**.
- Avaliamos e corrigimos por ordem de gravidade. Falha crítica tem prioridade sobre qualquer outro trabalho.
- Avisamos quem relatou quando a correção estiver no ar.

## Como protegemos os repositórios

- Todos os repositórios são privados.
- Varredura de segredos com bloqueio de push, alertas de dependências vulneráveis e análise de código (CodeQL) ligados em toda a organização.
- Nenhuma credencial é versionada.
